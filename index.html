⚖️ As 4 Leis Fundamentais do Nexus Matemático

Combinados oficiais de engajamento, proteção de dados e validação de aprendizagem na EE Felisberto Alves Carrejo.

01

Lei 1: Identidade Secreta (LGPD)

Cada estudante joga sob um Codinome Secreto e Avatar. No painel público jamais aparecem nomes reais ou notas vermelhas, e o XP reinicia a cada trimestre.

02

Lei 2: “Sem Defesa, Sem XP” (Questão Gêmea)

Listas feitas em casa servem como treino. Folhas copiadas de colegas ou geradas por I.A. valem 0 XP. Os pontos só são validados após resolver em sala (sem celular) a Questão Gêmea.

03

Lei 3: Missão Tutor Socrático

Ao usar Inteligência Artificial em casa para estudar, peça apenas dicas conceituais sem pedir a resposta pronta e registre todo o cálculo no caderno para ganhar XP de autonomia.

04

Lei 4: Foco Coletivo

Celular guardado na mochila durante as explicações e atividades, sendo liberado apenas quando autorizado pela professora para consulta ao ranking ou missões.

☁️ Sincronização Automática em Nuvem (GitHub + Google)

Conecte uma URL do Google Apps Script uma única vez. Depois disso, todo XP que você lançar no celular ou computador aparece automaticamente no link do GitHub para os alunos!

📦 Publicação Instantânea no GitHub Pages

Depois de salvar a URL acima, clique no botão abaixo para baixar o arquivo index.html já configurado com o endereço da sua nuvem embutido. Basta enviá-lo para o seu repositório no GitHub!

⚙️ Script do Google (2 Minutos)

  1. Abra qualquer Planilha Google nova em sheets.new.
  2. Vá em Extensões ➔ Apps Script, apague tudo e cole o código abaixo.
  3. Clique em Implantar ➔ Nova implantação ➔ App da Web.
  4. Em Quem pode acessar, selecione Qualquer pessoa e copie a URL gerada.
function doGet(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("Nexus_Nuvem_DB");
  var payload = { students: [], logs: [], updatedAt: "" };
  if (sheet) {
    var raw = sheet.getRange("A1").getValue();
    if (raw) {
      try { payload = JSON.parse(raw); } catch (err) {}
    }
  }
  return ContentService
    .createTextOutput(JSON.stringify(payload))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    if (data.pin !== "2027") {
      return ContentService
        .createTextOutput(JSON.stringify({ ok: false, error: "PIN inválido" }))
        .setMimeType(ContentService.MimeType.JSON);
    }
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = ss.getSheetByName("Nexus_Nuvem_DB") || ss.insertSheet("Nexus_Nuvem_DB");
    var stateToSave = {
      students: data.students || [],
      logs: (data.logs || []).slice(0, 120),
      updatedAt: new Date().toISOString()
    };
    sheet.getRange("A1").setValue(JSON.stringify(stateToSave));
    return ContentService
      .createTextOutput(JSON.stringify({ ok: true, updatedAt: stateToSave.updatedAt }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ ok: false, error: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
